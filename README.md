# 启动配置管理器 / Startup Preset Manager

这是一个本地 Windows 自启动预设工具的个人版本，供个人使用、开发参考、灵感分享和开源使用。

这是一个没有编程基础的人因居家办公而提出的个人需求，并借助 OpenAI Codex 进行开发的实验性脚本。
因本人没有任何代码基础，加上由AI编写，对代码本身没有保证性，开源并不意味着代码已经成熟或适合所有场景。
欢迎参观、学习、复用和改进，但请先理解它会涉及到和修改 Windows 的系统内容，并自行承担本机使用与二次开发的风险。


## 简介

> 用勾选框来管理 Windows 的第三方软件自启动，并根据你的选项把不同使用场景保存成预设，随时一键切换。

解决一些很日常的事：
电脑开机后，哪些软件应该自启动？
居家办公者，怎么迅速清空烦人的工作软件，让一次重启将电脑迅速切换到更休闲的状态
（某种意义上也能让人从心理上得到一次上下班的切换，而不只是退出几个软件...）

你可以把“工作”“游戏”“轻量模式”等不同习惯保存为预设，需要时一键载入，再统一应用到系统。
晚上睡前，应用“工作”预设，第二天打开电脑即可自启动你的工作软件
下班后，应用“游戏”预设，重启一下电脑，站起来喝杯水，即可恢复到没有工作打扰你的私人时刻。
（听起来很命苦的样子😭）
它并不能替代任何系统管理工具，只是把常见的自启动管理做得直白方便一点。

## 它能做什么

- 找出常见的、**已有的**第三方软件自启动项。
- 通过勾选决定软件下次登录或开机后是否自动启动。
- 管理注册表启动项、启动文件夹、登录/开机计划任务。
- 在高级模式下查看自动服务和部分第三方驱动。
- 保存多个命名预设，并在不同预设之间切换。
- 关闭启动文件夹项目时先本地暂存，而不是直接删除快捷方式。
- 完全本地化运行，不涉及联网内容。

## 使用前请注意

普通软件，例如下载器、聊天软件、截图工具、游戏平台等，通常可以放心按自己的需求勾选。

服务和驱动则不同。它们可能影响硬件、网卡、远程控制、灯效软件或安全软件，因此默认被隐藏在“显示高级项目（服务、驱动）”中。不了解用途时，请不要关闭它们。

本程序改变的是“以后是否自动启动”，不会关闭现在已经运行的软件。

## 快速开始

1. 下载`StartupPresetManager.exe`。
2. 打开运行。
3. 浏览列表：勾选代表启用，取消勾选代表禁用。
4. 点击“应用更改”。
5. 如需保存当前搭配，在预设框中输入名称，再点击“保存当前为预设”。

**修改机器级项目、计划任务、服务或驱动时，程序会提示你点击“以管理员身份重新打开”。**

## 本地数据与恢复

程序的设置保存在：

```text
%LOCALAPPDATA%\StartupPresetManager
```

这里包含预设、被暂存的启动文件夹项目，以及曾由本工具管理过的服务或驱动记录。需要备份时，备份整个这个文件夹即可。

删除该文件夹不会删除原有软件或系统启动项，但会失去预设，也可能需要手动找回被暂存的启动文件夹快捷方式。

## 它不是什么

- 它不是恶意软件查杀工具，也不是完整的系统安全审计工具。
- 它不会卸载软件、删除软件、结束正在运行的程序。
- 它不会覆盖所有罕见的持久化方式，例如浏览器扩展、WMI 事件订阅、Winlogon 设置或自定义 Shell。
- 它不是 Microsoft Sysinternals Autoruns 的替代品。

如果你需要排查恶意软件或异常自启动，请使用可信的安全工具，或向有经验的技术人员求助。
